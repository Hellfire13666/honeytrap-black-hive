# LIVE WATCH recipes

From the installed v0.3.1 folder, run in two terminals:

```sh
python3 LIVE_SIGNAL.py serve
```

```sh
python3 LIVE_WATCH.py
```

Open `http://127.0.0.1:8767/` and the demo at `http://127.0.0.1:8766/`. Results refresh every two seconds. For old v0.3.0 saved reports instead run `python3 LIVE_WATCH.py --reports "../HONEYTRAP-BLACK-HIVE-v0.3.0/LiveSignalReports"` adjusting the actual location.
